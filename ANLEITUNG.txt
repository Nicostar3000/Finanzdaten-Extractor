PDF Finanzdaten Extraktor – Anleitung (Kurz)
===========================================

Dieses Projekt liest Transaktionen aus Broker-PDFs (textbasierte PDFs) aus,
zeigt sie in einer GUI/Diagramm-Ansicht an und exportiert sie als CSV.

1) Voraussetzungen
-----------------
- Windows 10/11 (oder anderes OS mit Python)
- Python 3.10+ (empfohlen)

2) Installation (im Projektordner)
---------------------------------
PowerShell öffnen und in den Projektordner wechseln, dann:

  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  pip install -r requirements.txt

Alternative mit Python-Launcher:

  py -m venv .venv
  .\.venv\Scripts\Activate.ps1
  py -m pip install -r requirements.txt

3) Start (GUI)
-------------
Ohne Parameter startet das Programm im GUI-Modus:

  py main.py

In der GUI:
- Ordner oder einzelne PDFs hinzufügen
- "Als CSV speichern" exportiert direkt
- "Daten anzeigen & visualisieren" öffnet den Viewer (Tabellen, Diagramme, Filter, Export)

4) Start (CLI)
-------------
Die CLI läuft ausschließlich über main.py.

PDFs/Ordner verarbeiten:

  py main.py --input "testPDF"

CSV an einen Pfad schreiben:

  py main.py --input "testPDF" --output "output\\portfolio.csv"

Viewer nach der Verarbeitung öffnen:

  py main.py --input "testPDF" --chart

Wichtig:
- --output und --chart setzen --input voraus.

5) Testdaten (testPDF)
----------------------
Im Ordner testPDF liegen Beispiel-PDFs in Unterordnern (z. B. Finance-Free,
Handelsrepublik, Investbank). Diese eignen sich zum schnellen Testen.

Beispiel:

  py main.py --input "testPDF" --output "test-export.csv"

6) Ergebnis / CSV
-----------------
- Das CSV-Format ist Semikolon-getrennt (Excel-freundlich).
- Wenn der Zielname schon existiert, wird automatisch ein freier Name erzeugt:
  datei.csv → datei (1).csv → datei (2).csv

7) Häufige Probleme
-------------------
- "Keine PDF-Extraktionsbibliothek verfügbar":
  -> requirements installieren (pypdf ist Pflicht)

- Gescanntes PDF (kein Text):
  -> OCR notwendig; wird aktuell nicht unterstützt.

8) Struktur (kurz)
------------------
- main.py: Einstiegspunkt (GUI oder CLI)
- src/core/: PDF-Text extrahieren + Text parsen
- src/services/: Workflows/Pipeline
- src/export/: CSV-Writer
- src/gui.py + src/gui_viewer.py: GUI/Viewer
- src/apps/viewer/*: aufgeteilte Viewer-Logik (Charts/Filter)
